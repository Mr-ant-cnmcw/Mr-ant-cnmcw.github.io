# Part1：网络架构

## Q1. 为什么网络采取分层的设计？OSI模型是怎么划分的？

###  1.1
在生物学中，生物学家们通过对身体的结构，构造出了一套便于理解的体系：
- 细胞→组织→器官→系统→个体
 这套体系非常清晰地体现了’分层‘这一概念的好处：
 **采用分层的方式，让每一层专注于特定的功能，再通过标准接口协作**
如此，便可让一套复杂的系统有条不紊地运转起来~

### 1.2 
大自然中如此，我们人类的产物也是如此。
作为当今最复杂的系统（之一），互联网当然也采用了分层的架构。
 国际标准化组织（ISO）提出了一个理论参考模型 ：**OSI模型**
 这个模型一共有七层：


| 层级  | 名称    | 功能                   | 比喻                        |
| --- | ----- | -------------------- | ------------------------- |
| 7   | 应用层   | 为用户提供各种网络服务          | 你看到的各种APP和软件，比如浏览器、邮箱客户端。 |
| 6   | 表示层   | 数据格式化，加密解密           | 翻译官和保镖，负责翻译数据和保证安全。       |
| 5   | 会话层   | 建立、管理和终止通信双方的会话      | 负责沟通的建立和维护，就像上个世纪的电话接线员   |
| 4   | 传输层   | 提供端到端的可靠或不可靠数据传输服务   | 可靠的物流公司或黑心物流公司            |
| 3   | 网络层   | 进行逻辑寻址和路由选择，决定数据走哪条路 | 缺德地图持续为您导航                |
| 2   | 数据链路层 | 在相邻节点间传输数据帧，进行差错控制   | 让黑心物流公司的包裹精确投递到你小区的菜鸟驿站   |
| 1   | 物理层   | 比特流传输                | 装数据的大运                    |

  但在实际应用中，最常用的并不是OSI,而是采用了四层架构的**TCP/IP模型** ：


| OSI对应层级 | TCP/IP模型层级 |       功能       |
| :-----: | :--------: | :------------: |
|  7，6，5  |    应用层     | 直接为用户提供网络应用服务  |
|    4    |    传输层     |  核心协议是TCP和UDP  |
|    3    |    网络层     | 使用IP协议，负责寻址和路由 |
|   2，1   |   网络接口层    |  负责在物理网络上收发数据  |
## Q2. 相比于OSI模型，为什么TCP/IP模型采用了四层架构？

### 2.1 从**通信方式**角度来看：
OSI模型强调每个层次之间的清晰接口和分层通信，而TCP/IP模型更加实用，强调端到端的通信和互操作性。
### 2.2  从**具体协议**来看：
OSI模型没有指定具体的协议，而TCP/IP模型则是一套具体的协议集合，包括IP、TCP、UDP、ICMP、HTTP等。
   
  

## Q3.我们一般使用哪个网络模型？
当然是TCP/IP模型啦~

# Part2：网络硬件

## Q1. 路由器，交换机，集线器都是什么,他们有什么区别？
### 1.1 路由器：家门口的菜鸟驿站
工作于网络层，负责在不同的网络层级之间（家里的局域网与外网）转发数据。
### 1.2 交换机：贴条形码的分拣员
工作于数据链路层，负责根据数据的MAC地址（物理地址）将数据转发给目标设备端口。
### 1.3 集线器：被抛弃的大喇叭
工作于物理层，负责把从一个端口接收到的电信号放大，然后原样复制到所有其他端口上。
目前市面上很少见到。

## Q2. HTTP和HTTTPS有什么区别？
四个层面：

| 对比项   | HTTP        | HTTPS             |
| ----- | ----------- | ----------------- |
| 传输方式  | 明文          | 密文                |
| 加密协议  | 无           | TLS/SSL，混合加密      |
| 身份验证  | 无法验证服务端身份   | 需要数字证书，浏览器验证证书合法性 |
| 数据完整性 | 数据可能在传输中被暗改 | 通过MAC校验，确保数据未被篡改  |

P.S.  _HTTPS解决的是“路上被人偷听”的问题,不是“家门被撬”的问题。_

## Q3. DNS是什么？其有着怎样的层级结构？为什么用UDP不用TCP呢？
### 3.1是什么？
一份电话簿，核心作用是把对人类友好的、容易记忆的**域名**（比如 `www.homo.com`）转换成计算机通信所需的**IP地址**（比如 `114.514.191.810`）

### 3.2什么结构？
一个树状系统，从高到低分别是：根域（一个点  .  ），顶级域(.com或.org等)，二级域（homo.com），子域（www.homo.com）
### 3.3 为什么用UDP不用TCP呢？
其实都可以用，不过：

#### TCP：稳，安全可靠，但比较慢，适合对数据完整性要求极高的场景，比如发邮件，银行转账。

#### UDP：快，非常快，要连接有速度，要可靠性有速度，要数据顺序有速度，适合实时性要求高的场景，比如FPS，视频通话等。

## Q4. 什么是ARP协议?
### 通过IP地址找到对应的MAC地址,从而让数据能在局域网里精准送达。
在数据传到最后一层，即你家小区时，数据往往只有一个IP地址，但是不知道物理地址在哪里。就像外卖小哥知道你的门牌号，但是还是要问小区保安某栋某单元在哪里。
ARP协议就是这个指路的保安。

### 不过这个保安要先问你一遍，听到你的声音后才会把IP和物理地址记下来，记录在ARP缓存里。
