# Shapley值是什么？

shapley值，或者shapley值法，是一种n人合作对策中公平分配联盟总收益的数学方法。  
简单来说，就是怎样最公平地分钱。  

_其最开始是博弈论中的方法，后延伸到人工智能领域用于大模型输出结果的解释_

---

# 源于合作博弈论  

## 公式  
  
shapley值的具体公式如下：  

$ \phi_i(v) = \sum_{S \subseteq N \setminus {i}} \frac{(|S| - 1)! (n - |S|)!}{n!} [v(S \cup {i}) - v(S)]$    
  
    
        
其中，($\phi_i(v)$)表示成员i的Shapley值，(S)是包含成员i的所有子集，(v(S))是联盟S的收益，($v(S \cup {i})$)是成员i加入联盟S后的收益。


## 案例

我们先来看一个例子：
> A、B、C三个人共同植树，规定时间内一共要种500株树苗，种完得1000元奖励。   
> A单独完成只能种100株  
> B单独完成只能种125株  
> C单独完成只能种50株  
> A,B合作，能种270株  
> A,C合作，能种375株  
> B,C合作，能中375株  
>三人合作能够种完500株  
>问该怎么分配这1000元？

很明显，三个人的能力各不相同，如果按照平均分配的方法，肯定对能力强的人是不公平的。  
并且，这里的能力大小也有区别：比如丙单独种种不了多少，但是与别人合作时却能大幅增加种植效率。 

_我们可以计算每一个人加入一个“团队”时，为这个“团队”新带来的收益，这种新的收益我们叫做“边际贡献”_  

_然后把它为不同“团队”带来的收益加权平均，便可得到这个人“真正的价值”—————即shapley值_  

_这里的“团队”既可以是空的团队(空子集)，也可以是一个人的团队(只有一共元素的子集)_    





举个例子：
>我们按照A->B->C的顺序来看：  
>A：100  
>A+B：270  
>那么B的贡献就是：270-100=170  
>A+B+C：500   
>丙的贡献就是：500-270=230  

在这一种组合里，丙的贡献是最多的
同样的方法，我们排列组合三人的顺序，便可得到下面这张表格：

---

|概率  |顺序    |A的边际贡献|B的边际贡献|C的边际贡献|
|:----|:-------|:---------|:---------|:---------|
|1/6  |A->B->C |100       |170       |230       |
|1/6  |A->C->B |100       |125       |275       |
|1/6  |B->A->C |145       |125       |275       |
|1/6  |B->C->A |150       |125       |225       |
|1/6  |C->A->B |325       |125       |50        | 
|1/6  |C->B->A |150       |300       |50        |

>分别把ABC的边际贡献加起来求平均，便可得到每个人的shapley值


|角色           |A        |B        |C           |
|:-------------|:--------|:---------|:----------|
|shapley值     |161.67    |161.67    |176.67    |
|占比          |32.33%    |32.33%    |35.33%    |
 
 ---

这样就可以更加公平地根据每个人的贡献来分配奖励了。

## 性质

下面这些性质，理论上应该是是让shapley值法实现公平公正的原因，但只需要了解就好：

>1.有效性（Efficiency）：联盟的总价值等于各成员Shapley值之和。

>2.对称性（Symmetry）：成员的顺序或标记不影响利益分配结果。

>3.冗员性（Redundancy）：如果成员对任何参与的联盟没有贡献，则其利益为零。

>4.加法性（Additivity）：如果同时参与多个独立的合作项目，一个参与者在所有项目中的总分配，等于他在每个项目中分配的加和。



# 机器学习的可解释性

在机器学习领域，训练一个模型是家常便饭的事。一个训练好的模型通常是根据输入的某些特征来得到一个结果。  

然而，这个过程往往是无法判断的，就像一个黑盒，你只能看到放进去了什么，吐出来了什么。  

shapley值在一定程度上可以去解释说明这个黑色过程：  

_它能够准确的算出模型内部每个特征对最终结果的具体影响，不管是大小还是正负面。_   

比如：  
>对于一片地区的房价的某个样本，其基础价值有100w  
>模型推算得出最终房价：107w
>此时shapley值告诉你：
>政府的影响：+20w  
>环境的影响：+5W  
>交通的影响：-3w  
>附近有人跳楼：-15w  
>所以最终房价是107w


这通常是一种“马后炮”的方法，但是却能够较好的让研究者“看清”黑盒里面的过程。这极大地提高了研究者对该模型的理解和认识，也让模型的输出结果更有说服力。  

_因此，shapley值在传统机器学习和对解释性有较高要求的领域有着举足轻重的地位。_  

唯一的不足是，shapley值的计算非常缓慢，所以在实际使用中，人们大多使用一种近似算法，即**SHAP法**

## SHAP法  

### 安装

SHAP法有专门的python库，使用时要用pip或者conda先安装：  

pip安装
```
pip install shap  
```
conda安装
```        
conda install -c conda-forge shap  
```

### 核心组件：解释器  

SHAP 库为不同类型的机器学习模型提供了多种优化的解释器，以提高计算效率和准确性。  

* TreeExplainer: 专为基于**树**的模型（如 XGBoost, LightGBM, CatBoost, Scikit-learn 的决策树和随机森林等）设计的高速、精确的解释器。  
* KernelExplainer: 一种**模型无关**的解释器，可以用于任何模型，但速度相对较慢。它通过对输入数据进行扰动，并训练一个局部的、可解释的代理模型来估算 SHAP 值。  
* DeepExplainer: 专为**深度学习**模型（如 TensorFlow 和 Keras 构建的神经网络）设计，它结合了 DeepLIFT 和 Shapley 值的思想。  
* GradientExplainer: 同样适用于**深度学习**模型，它基于期望梯度的方法来近似计算 SHAP 值。  
* LinearExplainer: 用于解释**线性**模型。  
  
[具体代码文档请点此处](https://shap.readthedocs.cn/en/latest/)

## 总结  

Shapley值源于合作博弈论，核心思想很简单：**一个人的价值，取决于他能为团队带来多少额外的收益**——也就是"边际贡献"的加权平均。这种方法兼顾了公平性与合理性，既不会让能力强的人吃亏，也不会忽略那些"单打独斗不行、但很会配合"的成员。  

延伸到机器学习领域，Shapley值帮助研究者打开了模型的黑盒，量化每个特征对预测结果的贡献大小和方向，让模型从"不可知"变得"可解释"。虽然原始计算成本高，但SHAP等近似算法让它在实践中真正落地。  

无论是分钱还是理解AI，Shapley值都在回答同一个问题：**每一个参与者，到底值多少？**
